 核心设计：
 - time_schedules：命名的时间表字典，每个时间表是一个 [{start, end}, ...] 数组
 - active_time_schedule：当前生效的时间表名称，指向 time_schedules 中的某个 key
 - weekly_schedule：课表，与时间表独立，只依赖 period_count
 - 文件不存在时，自动生成 "默认" + "夏令时" + "冬令时" 三套模板

 切换时间表 & 冲突验证

 切换流程

 switch_time_schedule("夏令时")
   →验证1：time_schedules["夏令时"] 是否存在？ →不存在则报错
   →验证2：len(time_schedules["夏令时"]) == period_count？ →不相等则报错
   →通过：更新 active_time_schedule = "夏令时"
   →写入 JSON
   →刷新主窗口标签（时间段立即更新）

 进度条逻辑

 每秒触发（TimeManager 信号）:
   1. 获取当前时间 HH:MM
   2. 遍历当前时间表 period_times
   3. 找到 start ≤now < end 的课时 →这是活跃课时
   4. 计算进度 = (now - start) / (end - start) ×100%
   5. 更新该课时的进度条宽度
   6. 其余课时的进度条隐藏
   7. 如果当前不在任何课时内（课前/午休/放学后）→全部隐藏

 下课后：
   - 进度条自动消失（now ≥end）
   - 如果连续两节之间无间隔（end == next.start），第一节结束后立即切换到第二节

 switch_time_schedule 实现伪代码：
 def switch_time_schedule(self, name: str) -> bool:
     # 1. 存在性检查
     if name not in self.time_schedules:
         logger.error(f"时间表 '{name}' 不存在，可用：{list(self.time_schedules.keys())}")
         return False

     # 2. 节数一致性检查（核心冲突验证）
     target = self.time_schedules[name]
     if len(target) != self.period_count:
         logger.error(
             f"无法切换时间表：'{name}' 为 {len(target)} 节，"
             f"当前 period_count={self.period_count}，节数不匹配"
         )
         return False

     # 3. 切换
     self.active_time_schedule = name
     self.period_times = target
     self._save_schedule_data_to_file()
     logger.info(f"时间表已切换为 '{name}'（{len(target)} 节）")
     return True

 默认时间表生成逻辑：
 - "默认"：8:00 起，上午 4 节 (45min + 10min 课间)，午休，下午 3 节
 - "夏令时"：8:00 起，上午下午各推迟半小时（模拟夏季作息）
 - "冬令时"：8:30 起，整体后移（模拟冬季作息）

 period_count 迁移逻辑（升级）：
 - 遍历 time_schedules 中所有时间表，每个都做截断/补齐
 - 对 weekly_schedule 中每天做截断/补齐
 - 迁移后写入 period_count 字段

 update_progress 逻辑（核心功能）：
 def update_progress(self, time_str: str):
     """每秒由 TimeManager 回调触发。"""
     now = time_str[:5]  # "HH:MM"
     times = self._theme.get_period_times()

     active_found = False
     for i, t in enumerate(times):
         bar = self.period_bars[i]
         if not active_found and t['start'] <= now < t['end']:
             # 当前课时 →计算进度
             elapsed = (now_minutes(now) - now_minutes(t['start']))
             total = (now_minutes(t['end']) - now_minutes(t['start']))
             pct = elapsed / total if total > 0 else 0
             bar.setFixedWidth(int(self._win_width * pct))
             bar.setVisible(True)
             active_found = True
         else:
             bar.setVisible(False)

 2. 主窗口显示今天科目（空白）+ 进度条（上课时间可见）
 3. 快捷编辑修改第一节 →JSON 确认写入
 4. 打开设置 →表格显示全周课表，所有单元格可编辑
 5. 表格中双击单元格 →下拉选科目 →保存 →JSON 确认
 6. 设置中切换时间表 →节数不匹配弹窗提示
 7. 重启 →所有数据保持

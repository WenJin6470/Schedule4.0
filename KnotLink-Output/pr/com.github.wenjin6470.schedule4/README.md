# Schedule 4.0

> 桌面浮动电子课表系统 — 半透明置顶窗口实时显示课时科目与当前时间

Schedule 4.0 是一款 Windows 桌面浮动课表应用，以半透明置顶悬浮窗的形式在屏幕右上角显示：
- **实时数字时钟**（HH:MM:SS）
- **当日课时科目列表**，当前课时自动高亮（红色=上课中，橙色=即将上课）
- **快捷编辑**功能，一键修改课表
- **临时换课**支持，指定日期自动生效
- **考试模式全屏**（墨绿色背景 + 科目/时间编辑）
- **创意模式全屏**（随机壁纸 + 红色大字时钟）

---

## 接口列表

| 接口 | 说明 |
|------|------|
| `get-lesson-state` | 查询当前实时上课状态：是否上课/课间/放学、当前科目、剩余时间、下一节课 |
| `get-today-schedule` | 获取当天（或指定星期）完整课表，含科目、起止时间、分隔线位置 |
| `swap-course` | 临时换课：记录换课信息，指定日期当天自动生效，过期自动清理 |
| `enter-fullscreen` | 进入全屏模式（考试模式 / 创意模式） |
| `exit-fullscreen` | 退出全屏，恢复浮动窗口 |

## 信号列表

| 信号 | 说明 |
|------|------|
| `onClassStart` | 上课事件 — 新一节课开始时推送，附带科目名、课时序号、起止时间 |
| `onClassEnd` | 下课事件 — 一节课结束时推送，附带下一节课预告和课间剩余时间 |
| `onDayEnd` | 放学事件 — 当天所有课程结束时推送 |
| `onEventTrigger` | 自定义事件触发 — 系统时间到达「事件系统」规则设定的日期与时间时推送，附带事件名称/日期/时间 |
